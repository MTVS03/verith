# 2. regime 규칙 명세

`docs/regime_rules.md`

국면 분류의 결정론적 규칙을 정의한다. 이 문서가 `regime/rules.py`·`regime/multiframe.py`(코드)와 `observability/regime_test.py`(검증 ②)의 **기준**이다. 셋이 항상 일치해야 한다.

> 아래 조건의 **구조**(어떤 지표를 조합하는가)는 확정이다. **수치**(임계값·기간)는 MVP 기본값이며 백테스트·오류 분석 결과에 따라 조정할 수 있다. 수치는 코드에 하드코딩하지 않고 `config.py`에서 관리한다.

### 1단계 — 일봉 1차 국면 (우선순위 순)

**위에서부터 검사하며, 처음 만족하는 것으로 확정한다(if-elif). 우선순위가 곧 순서다.**

| 순위 | regime | 판정 조건 (구조) |
| --- | --- | --- |
| 1 | **과매도 반등 관찰** | RSI ≤ `RSI_OVERSOLD` **AND** 주요 지지 근처 **AND** 반등 캔들 |
| 2 | **과열** | RSI ≥ `RSI_OVERBOUGHT` **AND** 볼린저밴드 상단 근처 |
| 3 | **상승 전환 관찰** ※ | 현재가 > 20MA **AND** 5MA > 20MA **AND** 20MA 기울기 상승 전환 **AND** RSI < `RSI_OVERBOUGHT` |
| 4 | **상승 추세 유지** | 현재가 > 20MA **AND** 정배열(5MA>20MA>60MA) **AND** 20MA·60MA 우상향 **AND** RSI < `RSI_OVERBOUGHT` |
| 5 | **하락 추세** | 현재가 < 20MA **AND** 역배열(5MA<20MA<60MA) **AND** 20MA 기울기 하락 |
| 6 | **횡보** | 위 어디에도 안 걸림 (기본값) |

※ 3번 라벨은 `bullish_reversal_watch`, 표시 라벨은 "상승 전환 관찰"로 확정한다. "전환 관찰"은 예측 뉘앙스를 줄이고 관찰된 신호를 설명하는 표현이다.

**우선순위 근거:** 극단 상태(과매도·과열)를 추세보다 먼저 검사한다. "정배열 + RSI 72"는 추세유지가 아니라 **과열**로 잡아야 정직하다.

**3·4번 분리 근거:** "상승 전환 관찰"(3)은 정배열이 완성되기 전, 전환 신호가 관찰되는 단계다(20MA>60MA 아직 아님). "상승 추세 유지"(4)는 정배열이 완성된 단계다. 3번을 4번처럼 빡세게(정배열 필수) 잡으면 거의 안 뜨므로 분리한다.

**판단 불가:** 규칙 검사에 필요한 지표가 부족하면(예: 60MA 계산 불가) `final_regime = 판단 불가`로 처리하고 이후 종합·신뢰도를 스킵한다.

### 2단계 — 멀티프레임 보정

일봉 1차 국면을 주/월봉 추세로 보정하되, **라벨은 바꾸지 않고** `alignment_flag`와 `regime_context`만 채운다.

**보정 기준 (월봉 우선):**

- `alignment_flag`는 **월봉 추세를 우선 기준**으로 판정한다.
- **월봉이 `unavailable`이면 주봉 추세를 대체 기준**으로 사용한다.
- 주봉과 월봉이 서로 다르면 **월봉을 우선**하고, 주봉 차이는 `regime_context`에 보조 맥락으로 서술한다.
- 월봉·주봉 모두 `unavailable`이면 `alignment_flag=neutral`, `regime_context`에 "상위 타임프레임 데이터 제한"을 명시한다.
- 기준 상위 추세가 `sideways`(또는 `unavailable`)이면 상승/하락 방향이 명확하지 않으므로 정합/역행으로 판정하지 않고 `alignment_flag=neutral`로 둔다.

**정합/역행 판정 (기준 추세 = 위 규칙으로 정해진 월봉 또는 주봉):**

| 일봉 국면 성격 | 기준 추세 | alignment_flag |
| --- | --- | --- |
| 긍정 계열 (상승 전환/유지) | 상승 | 정합 |
| 긍정 계열 | 하락 | 역행 |
| 부정 계열 (하락) | 하락 | 정합 |
| 부정 계열 | 상승 | 역행 |
| 방향성 있는 국면 | 횡보(sideways) | 중립 |
| 방향성 있는 국면 | 판단불가(unavailable) | 중립 |
| 중립 (횡보/과열/과매도) | any | 중립 |

**regime_context 생성 예:**

- 정합: "상위 추세(월봉 상승)와 방향이 일치합니다."
- 역행: "월봉 추세는 하락으로, 일봉의 긍정 신호는 대세 하락 안의 단기 반등일 수 있습니다."
- 주봉·월봉 불일치: "월봉 추세는 하락이나 주봉은 상승으로, 상위 두 추세가 엇갈립니다(월봉 기준 판정)."
- 월봉 미확보: "월봉 데이터가 없어 주봉 추세(상승)를 상위 기준으로 사용합니다."

`final_regime`은 일봉 라벨 그대로. 보정은 flag·context에만 반영.

### 3단계 — 보조 판정 정의 (구조는 확정, 수치는 config)

1단계 규칙의 모호한 표현을 코드가 판정할 수 있게 정량 정의한다.

| 표현 | 정의 (구조) | config 상수 |
| --- | --- | --- |
| **주요 지지 근처** | 최근 20일 저점(또는 pivot low)과 현재가 차이가 임계% 이내 | `NEAR_SUPPORT_THRESHOLD_PCT` |
| **반등 캔들** | 종가 > 시가 (양봉), 또는 아랫꼬리 길이 > 몸통 × 배수 | `REBOUND_WICK_RATIO` |
| **볼린저밴드 상단 근처** | 현재가 ≥ 볼린저밴드 상단 × 임계비율 | `NEAR_BAND_THRESHOLD` |
| **우상향** | 최근 N일 이동평균 기울기 > 임계값 | `SLOPE_LOOKBACK_DAYS`, `SLOPE_MIN` |
| **기울기 상승 전환** | 20MA 기울기가 음→양 전환 (최근 N일) | `SLOPE_LOOKBACK_DAYS` |

### 계산 상수 (config.py · MVP 잠정값)

| config 이름 | 값 | 설명 |
| --- | --- | --- |
| `RSI_OVERBOUGHT` | 70 | 과열 판정 |
| `RSI_OVERSOLD` | 35 | 과매도 반등 판정 |
| `MA_WINDOWS` | [5, 20, 60] | 이동평균 기간 |
| `MIN_DAILY_BARS` | 60 | 이보다 적으면 판단 불가 |
| `NEAR_BAND_THRESHOLD` | 0.98 | 볼밴 상단 근처 |
| `NEAR_SUPPORT_THRESHOLD_PCT` | 0.02 | 지지 근처 (2%) |
| `REBOUND_WICK_RATIO` | 1.5 | 반등 캔들 아랫꼬리 배수 |
| `SLOPE_LOOKBACK_DAYS` | 5 | 기울기 판정 기간 |
| `SLOPE_MIN` | 0 | 우상향 최소 기울기 |

*위 값은 MVP 기본값이며 백테스트·오류 분석으로 조정한다.*

### 검증 ②가 테스트하는 것

이 명세의 모든 규칙(1·2·3단계)을 입력→라벨 테스트로 검증한다.

예:

```markup
입력: 정배열 + RSI 72 + 볼밴상단        → 기대: 과열 (추세유지 아님)
입력: 현재가>20MA + 5MA>20MA + 기울기전환 + RSI 60  → 기대: 상승 전환 관찰
입력: 정배열 완성 + 우상향 + RSI 60       → 기대: 상승 추세 유지
입력: RSI 33 + 지지 2% 내 + 양봉         → 기대: 과매도 반등 관찰
입력: 일봉 과열 + 월봉 상승              → 기대: final_regime=과열, alignment_flag=중립
입력: 봉 40개 (60MA 불가)               → 기대: 판단 불가
```
